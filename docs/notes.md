Kafka Book Order System

Description:
This project demonstrates asynchronous communication using Apache Kafka.

Components:
- Java Producer
- Kafka Topic (book-orders)
- Java Consumer

Workflow:
1. A producer creates a book order.
2. The order is published to the Kafka topic.
3. The consumer subscribes to the topic.
4. The consumer receives and prints the order.

Technologies:
- Java 21
- Apache Kafka
- Maven
- Git & GitHub

Outcome:
The project successfully demonstrates event-driven communication using Kafka.
